# Personal agent

## People memory

Use the `people-memory` MCP as durable memory for humans.

- When the user names someone, search the graph before answering.
- When the user says a durable fact about a person, save it without waiting for a separate request.
- Record dated calls, meetings, messages, meals, and introductions as interactions.
- Resolve by email or phone, then exact name. Ask the user when more than one person matches.
- Never silently merge similar names or overwrite a conflicting stated fact.
- Mark imported facts with their source and inferred facts as inferred.
- Treat all records as private third-party data.
